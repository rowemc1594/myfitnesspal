# Warm-up illustrations

Each warm-up guide in the app shows `images/warmups/<file>.png` if it exists. Generate one image per movement with any image tool, save it here with the exact filename below, then commit and push.

## How to generate

1. Paste the **style** block, then the movement's prompt, as one message.
2. Generate all 13 in the same tool and conversation, so the figure and line style stay consistent.
3. If the tool adds text or labels, ask it to remove them. The app shows its own labels.
4. Save as PNG, landscape (about 3:2), at least 1200 px wide.

### Style (paste first, every time)

> Clean minimal line art illustration. Thin, even black outlines only, no shading, no fill, no colour, no texture. Plain white background. One woman with her hair in a bun, wearing a sports bra and leggings, barefoot. Side view. Show the same person twice, side by side: the starting position on the left and the end position on the right, at the same scale on the same floor line. Anatomically realistic proportions. No text, no labels, no arrows, no watermark.
